# 動漫角色 MV 工作流

一支 4～5 分鐘、1080p60 的角色 MV。Claude 負責分鏡、提示詞、審圖、動畫與剪輯；使用者負責方向、挑圖、給回饋。

這份流程來自第一支實作（林翩翩 × ヨルシカ〈第一夜〉）。那次走了很多冤枉路，問題都寫在 `references/case-study.md`。下面每一個「關卡」都是為了不再重犯同一個錯。

## 鐵則

1. **先確認再輸出**。任何素材或設定改完，先給使用者看小樣，等確認才出完整影片。不要自己一路跑到成品。
2. **回饋集中記錄**。看片回饋一律寫進 `待改清單.md`，使用者說「一起改」才動手。
3. **成品不覆蓋**。每次完整輸出都用新檔名（`_v2`、`_v3`…）。
4. **交圖前放大檢查**：臉、瞳色、手（數量、關節、左右手）、道具。自己判斷不可靠時明講「手部請你確認」。細則見 `references/review-checklist.md`。
5. **版權素材不外流**：原作 CG、立繪、歌曲、歌詞、他人同人圖，不放進任何公開位置；來源不明的圖先問。見 `references/copyright.md`。

## 流程與關卡

完整說明見 `references/workflow.md`。

| 階段 | 產出 | 關卡（過了才往下） |
|---|---|---|
| 0 準備 | 歌曲、歌詞時間軸、原作文本、角色立繪／CG、可用工具清單 | 確認版權狀態、確認有哪些生圖／動畫工具與額度 |
| 1 概念與分鏡 | 每句歌詞對應的鏡頭表 `shots.json` | 使用者通過概念；**不逐句硬扣歌詞**，以情緒連貫為主 |
| 2 定畫風 | 每種素材來源各 3 張測試圖 | **一次定死**：基準畫風、角色 LoRA、統一工序。之後不再換工具 |
| 3 動畫可行性測試 | 一段 5 秒動畫的 60fps 小樣 | **先驗幀率與速度**（見下），確認工具後才排動畫鏡頭 |
| 4 生圖與審圖 | 每鏡定稿圖 | 分段審圖，使用者通過才進合成 |
| 5 動畫 | 重點鏡頭動畫 | 每段先出小樣；人物臉部盡量不動 |
| 6 合成 | 各段時間軸 `timelines.py`、字幕 | 分段小樣通過 |
| 7 出片 | 1080p60 主檔（另可轉 Discord 版） | 使用者確認後才輸出 |

## 動畫：先過幀率關（最容易翻車）

多數圖轉影片模型（MiniMax H3、即夢 Seedance）只輸出 **24fps**，而且面板不能選 60fps。

- **不要用補幀**。光流和 RIFE 遇到大動作會猜錯，出現拖影、糊、變形。
- **用「慢動作生成」**：提示詞開頭寫「慢動作，動作緩慢連續」，時長設成片中需要的 **2.5 倍**，回來後把每一格當 60fps 的一格播放。每一格都是模型畫的真畫面。
- **小幅度快動作（抽泣、顫抖）模型不太會放慢**，整段 2.5 倍速會太急。用時間軸的 `timemap` 分段變速：情緒段慢放（約 1.3 倍），轉場段快放。
- 兩張關鍵畫面（例如蹲著哭 → 含淚抬頭）用**首尾幀**一次生成一鏡到底，比動畫接貼圖自然。
- 細節與即夢操作見 `references/animation.md`。

## 合成引擎

`scripts/` 是可直接用的引擎，用法見 `references/compose-engine.md`：

- `compose.py`：CPU 版 2.5D 合成（推拉搖、深度視差、燈火／雨／浮塵、轉場、顆粒）。
- `compose_gpu.py`：GPU 版（PyTorch＋h264_nvenc），約快 5 倍，`--fps 60` 出 60fps。
- `subs.py`：雙語字幕，副歌直書、主歌依留白擺放、逐字墨暈浮現；也負責片名與片尾字卡。
- `timelines_template.py`：時間軸範本，複製成 `timelines.py` 再改。
- `gen.py`／`enhance.py`／`i2v.py`／`upscale.py`／`layers.py`：本機 ComfyUI 生圖、SeedVR2 去噪、MiniMax H3 圖轉影片、影片放大、去背與深度圖。

## 搭配 cinematic-director

分鏡定好後、生圖之前，可以用 [cinematic-director](https://github.com/cOkieeman/xiaoyou-aigc-cinematic-director) 把每個鏡頭轉成電影攝影級提示詞（光影、構圖、色板、正負向 prompt）。做法見 `references/cinematic-director.md`。

## 轉場與畫面原則（使用者驗證過）

- 用畫面元素轉場：燈光擴散（bloom）、從道具泛光進回憶、柔和溶接退出回憶。程式疊上去的特效（花瓣、雨絲）容易像貼紙，能用畫面本身的元素就不要疊。
- 臉部附近不要用「暗部先溶」類轉場（會出現臉浮在黑洞裡）。
- 避免擺拍：人物不要站中央把東西伸向鏡頭；要像抓拍。
- 遠景小臉一定崩：改背影，或拉近到臉夠大。
- 手一直畫錯就重構成手不入鏡的構圖，不要反覆局部重畫；只差一點時，可只重畫手再羽化貼回原圖。
- 亮度落差大的鏡頭（夜→白天回憶）一定要有過渡，不要硬切或 0.3 秒白閃。
