# 版權與素材

## 不放進公開倉庫或分享出去的東西

- 原作 CG、立繪、道具設定圖、劇本文本。
- 歌曲音檔、歌詞原文與翻譯。
- 他人繪製的圖（同人圖、約稿圖），除非取得授權。
- 任何 API 金鑰、帳號資訊。腳本一律從使用者家目錄的設定檔讀金鑰，不寫死、不印出。

## 參考圖的來源要先確認

第一支 MV 裡，一張被當成「官方結局圖」的圖其實是其他畫師的約稿圖。發現後：

1. 立刻停用它當底圖或參考，記進專案說明。
2. 以它生成的素材列出來，由使用者決定替換或保留。
3. 後來朋友取得原畫師授權（「按官方圖處理」），才恢復使用，同樣記進專案說明。

## 發布說明的素材欄

照實寫出使用的來源，例如：原作官方 CG／Codex · image2.5／ComfyUI（Krea2、Anima）／即夢 Seedance／MiniMax H3。

## 平台確認

即夢等平台送出前會要求素材授權聲明。這要使用者本人同意，不能代按。
