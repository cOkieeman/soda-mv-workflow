# 動畫

## 原則

- 動畫要讓畫面意思更清楚才做。沒必要不要硬做，靜態圖＋2.5D 運鏡往往更穩。
- 人物臉部盡量不動，只動頭髮、衣物、環境（雨、燈、花瓣、雲）。
- 提示詞明寫「保持原圖畫風、構圖、人物臉部，不要變臉」「鏡頭固定」。

## 幀率問題（第一支踩過的坑）

| 做法 | 結果 |
|---|---|
| H3 原生 24fps 直接放進 60fps 片子 | 一格重複多次，卡頓 |
| 光流補中間格 | 大動作時猜錯，前後兩格疊成拖影 |
| RIFE 補幀 | 中間格糊、變形，使用者覺得很糟 |
| **慢動作生成，24fps 每格當 60fps 播** | 每一格都是真畫面，最順 |

### 慢動作生成

1. 算片中這一鏡需要的長度 L 秒（例如 2.6 秒）。
2. 生成時長設 `L × 2.5`（例如 6 秒，24fps 共 145 格）。
3. 提示詞開頭寫「慢動作，動作緩慢連續。」
4. 合成時直接用全部格數鋪滿 L 秒（compose 的 `seq` 會自動依鏡頭長度取樣）。

### 分段變速（timemap）

小幅度快動作（抽泣、顫抖）模型不太會放慢，整段 2.5 倍速會太急。在鏡頭加 `timemap`：

```python
"timemap": [(0.0, 4.0), (5.0, 10.5), (7.5, 18.0), (11.8, 30.0)],
# (鏡頭內秒數, 素材秒數)，素材以 24fps 計，中間線性內插
# 0–5 秒播素材 4–10.5 秒（約 1.3 倍，抽泣自然）；之後加速帶過轉場；最後抬頭推近
```

曾試過把抽泣逐拍對到鼓點，使用者覺得不如單純變速自然，放棄了。

### 首尾幀一鏡到底

兩張關鍵畫面（蹲著哭 → 含淚抬頭推近），用首尾幀模式一次生成，比「動畫接貼圖再推鏡」自然。尾幀可以直接用原 CG 裁成想要的推近構圖。

## 工具

### 即夢（Seedance 2.5）

- 模式：視頻生成 → Seedance 2.5 → 首尾幀；比例自動；720P（回來可再用 SeedVR2 放大）；時長 0～30 秒。
- 輸出 1280×720（或依首幀比例）、24fps。面板沒有幀率選項。
- 點數（標準會員時）：720P 約每秒 20 點，1080P 約每秒 64 點。30 秒 720P＝600 點。
- **先關掉「AI 生成水印設置」**，否則畫面左上會燒進「AI生成」標籤。會員才能去品牌浮水印。
- 下載要用影片右上角的下載按鈕拿原檔（約 10～14 Mbps）。直接抓網頁 `<video>` 拿到的是約 1 Mbps 的預覽串流。
- 連續下載多個檔案時，Chrome 可能會擋自動下載，要使用者允許。
- 送出前會跳「安全確認」（素材授權聲明），要使用者本人同意。

### MiniMax H3（本機 ComfyUI）

- 24fps，16GB 顯存建議 0.4MP。後段姿勢常漂移，要接下一張 CG 時只取前段。
- `i2v.py <鏡號> <圖> "<動作描述>" --sec 5 --seed N`，輸出 `clips/<鏡號>_<圖名>_<seed>/frame_*.png`。

### 放大

- 圖：`enhance.py <圖> --mode seedvr2`（SeedVR2 7B，16GB 用 blocks_to_swap 32）。
- 影片逐格：`upscale.py`（batch 9、VAE 分塊 512，用 `--cap` 只放大需要的格數）。
- 重 GPU 工作一次只排一個，不要和合成或其他 SeedVR2 疊在一起。
