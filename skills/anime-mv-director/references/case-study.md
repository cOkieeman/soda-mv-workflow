# 實作紀錄：林翩翩 × ヨルシカ〈第一夜〉

第一支用這套流程做的 MV（4:44，1080p60）。素材不公開，這裡只記問題和解法。

## 結果

- 61 鏡分鏡，最後約 50 鏡進片：原作 CG、GPT 生圖（Niu 中轉 image2.5／Codex）、本機 ComfyUI（Krea2、Anima＋自訓角色 LoRA）、即夢 Seedance 2.5 動畫、MiniMax H3 動畫、使用者自己用 Midjourney 做的一段動畫。
- 2.5D 合成、雙語字幕（副歌直書）、片尾字卡與角色曲。
- GPU 合成 60fps，全片約 9～25 分鐘。

## 走過的冤枉路

### 1. 前期沒定好畫風和動畫方案

生圖工具依序換過：本機 Krea2 → Niu 中轉 → Codex → 本機 Anima → 使用者的平塗畫風；動畫換過 MiniMax H3 → 光流補幀 → RIFE → 即夢。很多是做到一半才發現不行，例如本機空景跑成賽璐珞風、Niu 某天全面回 HTTP 477、H3 只有 24fps。

**改成**：階段 2「定畫風」每種來源先出 3 張測試圖，使用者選定後寫死；換工具要回到這一步。

### 2. 動畫幀率問題太晚發現

全片做到 60fps 才發現：H3 原生 24fps 又被慢放，卡；光流補格有拖影；RIFE 補幀又糊又變形；改用即夢後 24fps 以 2.5 倍速播，抽泣顫抖太急。

**改成**：階段 3「動畫可行性測試」在大量生圖前就做，用一段 5 秒動畫跑完到 60fps 小樣。定案做法是「慢動作生成＋每格當 60fps 播」，小動作再用 timemap 分段變速。

### 3. 審片回饋零散、反覆改同一處

待改清單最後累積 16 項，其中同一個鏡頭（27 墨色記憶）的特效改了五次：白雨絲 → 褐墨線 → 墨跡暈染 → 多滴水 → 淚滴 → 單滴暈滿。

**改成**：
- 回饋集中寫進待改清單，使用者說「一起改」才動手。
- 改特效前先問清楚想要的感覺（例如「淚水打濕回憶的畫」），用一兩句話複述確認，再做小樣；不要先做再猜。
- 有多種做法時，一次出 2～4 個版本並排給使用者選。

### 4. 版權素材

一張被當成官方結局圖的其實是其他畫師的約稿圖，發現時已用它生成了三個鏡頭。後來取得授權才恢復。

**改成**：階段 0 就確認每張參考圖的來源；公開分享（例如這個倉庫）一律不含原作素材、歌曲和歌詞。

## 使用者給過、證實有效的原則

- 畫風統一往原版 CG 靠。
- 手一直錯就重構成手不入鏡；只差一點就只重畫手再貼回。
- 遠景小臉一定崩。
- 避免擺拍，要抓拍感。
- 不必逐句硬扣歌詞。
- 合成的特效濾鏡（貼上去的花瓣）會顯得廉價，改讓畫面本身的元素動。
- 動畫不硬做；人物臉部盡量不動。
- 使用者自己做的素材優先。
- 先確認再輸出；成品不覆蓋。
